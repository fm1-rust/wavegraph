# FM-1 display fonts

These four one-bit ASCII atlases are byte-for-byte copies from
`embedded-graphics` 0.8.2. They use the public-domain X.Org misc-fixed fonts.
The FM-1 pairs each bitmap in upper flash with the crate's matching glyph
mapping and metrics. [Upstream font sources](https://github.com/embedded-graphics/embedded-graphics/tree/f785ffab09059a3dc1243cffe8f5c769548dcc69/fonts).
